# DuaTiga Coffee Space

Snapshot source website DuaTiga Coffee Space.

- `App.jsx`, `Reservation.jsx`, dan `data.json`: source aplikasi React dan data situs.
- `assets/img/`: gambar dan logo yang dirujuk oleh source.
- `package.json` dan `package-lock.json`: metadata serta dependensi proyek.

Log deployment, hasil pemeriksaan sementara, dan `node_modules` tidak disertakan. Repository ini berisi source; keluaran siap-terbit tidak disalin ke dalamnya.
